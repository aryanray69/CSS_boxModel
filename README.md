# Box Models Assignment

## Overview
This project demonstrates the use of the CSS Box Model by creating a simple webpage containing:

- A space-themed image
- A clickable button linked to the image source
- Proper use of width, height, padding, borders, and layout styling

## Project Structure

Aryan_Task4/
│
├── index.html
├── style.css
└── README.md

## Features

- Responsive layout using viewport units (vw and vh)
- Full-width image display inside a bordered section
- Gradient background button section
- Large clickable button
- Demonstrates CSS Box Model properties:
  - Margin
  - Padding
  - Border
  - Width
  - Height
  - Box-sizing

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Download or clone the project.
2. Make sure `index.html` and `style.css` are in the same folder.
3. Open `index.html` in any web browser.

### Using VS Code

1. Open the project folder in VS Code.
2. Install the Live Server extension.
3. Right-click on `index.html`.
4. Click **Open with Live Server**.

The webpage will open in your default browser.

## Output

The webpage displays:

- A bordered section centered on the page
- A space image occupying most of the section
- A gradient-colored button area below the image
- A large "Click Me" button that redirects to the image source when clicked
